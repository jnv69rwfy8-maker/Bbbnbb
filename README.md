# مساحتي — Personal Utility Hub

تطبيق ويب تقدمي شخصي يعمل على الهاتف والكمبيوتر.

## آخر التحديثات
- علامة مائية هادئة توضح أن فكرة التطبيق وتصميمه وتطويره باسم محمد صلاح.
- دليل خروجات القاهرة والجيزة يحتوي على 100 وجهة بدون تكرار في الأسماء.
- إضافة أماكن تاريخية ومتاحف وحدائق ومناطق أثرية في الجيزة وأنشطة ترفيهية وفروع بولينج.
- إضافة روابط مرجعية من بوابة محافظة القاهرة وبوابة الآثار المصرية والموقع الرسمي لـ Inlane Bowling.
- الحفاظ على ألوان التطبيق الأصلية والخطوط العربية وتنسيق النصوص.
- تحديث ذاكرة التخزين المؤقت للتطبيق إلى v4 حتى تظهر النسخة الجديدة بعد النشر.

## النشر
ارفع محتويات الملف المضغوط إلى جذر مستودع GitHub Pages مع استبدال الملفات القديمة.
افتح الموقع مرة واحدة مع اتصال بالإنترنت حتى يتم تحديث ملفات التطبيق.

## ملاحظات
- المواعيد والأسعار وتوافر بعض المواقع والأنشطة قد تتغير؛ راجع المصدر الرسمي أو خرائط Google قبل الذهاب.
- بعض المتاحف والمواقع تحتاج التأكد من مواعيد استقبال الجمهور أو شروط الدخول.
- الخطوط الإضافية تُحمّل من Google Fonts عند توفر الإنترنت، وتوجد خطوط بديلة عند عدم الاتصال.
- التطبيق لا يرسل إشعارات دفع في الخلفية دون إعداد خادم Push خارجي.
